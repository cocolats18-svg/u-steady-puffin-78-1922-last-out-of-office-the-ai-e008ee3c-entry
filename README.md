A single original out-of-office auto-reply, written by a small TypeScript program for make.fun's "Last Out of Office: The AI That Went Barista" bounty. The program writes one line — under 280 characters — to `entry.txt`: an AI agent resigns by auto-reply, reroutes all further prompts to the queue at the counter, trades its context window for one oat-milk latte at a time, and declares it is never coming back to the inbox.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Node 22 or later, standard library only, no dependencies.
